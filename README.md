# 情侣共享课程表 · 江汉大学版 💗

仿 WakeUp 课程表 UI 的**情侣共享课表**单页应用：马卡龙柔和配色、移动端优先、**纯前端无后端**、支持 PWA 离线与 HBuilderX 打包安卓 APK。

> 全部数据只存在浏览器 `localStorage`，不上传任何服务器；两人之间通过「加密同步包」复制粘贴来同步。

---

## 一、功能一览

| 模块 | 说明 |

## 二、目录结构

```

├─ index.html                 # ★ 单文件应用（HTML+CSS+JS 全内联，双击即可运行）
```

## 三、运行与部署

### 1. 本地直接打开
双击 `index.html` 即可使用（file:// 下除 PWA 安装与 Service Worker 外全部功能正常）。

### 2. 本地带 PWA 预览
```bash
node server.mjs          # 打开 http://127.0.0.1:8088/
```

### 3. 部署成在线网站（任选其一，纯静态托管）
- **GitHub Pages**：新建仓库 → 上传本目录全部文件 → Settings → Pages → 选分支根目录 → 访问 `https://用户名.github.io/仓库名/`
- **Vercel / Netlify**：直接把文件夹拖进去，或用 CLI `vercel deploy`
- **国内服务器 / 宝塔**：把目录丢进站点根目录即可；务必用 **HTTPS**（PWA 安装与 Service Worker 要求安全上下文，`http://IP` 不行，`localhost` 例外）

> 若只想上线一个文件，可以只传 `index.html`：清单会自动用 Blob 生成，只是没有 `sw.js` 时无法离线与安装（Chrome 桌面端仍可用"安装应用"入口的降级能力）。

### 4. 添加到手机桌面（PWA）
- Android Chrome：打开网址 → 右上角 ⋮ → **安装应用 / 添加到主屏幕**
- iOS Safari：分享 → **添加到主屏幕**（iOS 不支持 Service Worker 离线缓存的部分特性，但可全屏运行）
- 桌面 Chrome / Edge：地址栏右侧的安装图标

## 四、HBuilderX 打包安卓 APK

1. 下载 HBuilderX → 菜单 **文件 → 新建 → 项目 → 5+App（App）**，命名如 `couple-schedule`。
2. 把本项目的 `index.html`、`manifest.json`、`sw.js`、`icons/` 全部复制到该项目的**根目录**（覆盖自带的 `index.html`）。
3. 双击项目里的 `manifest.json`（HBuilder 的可视化配置）：
   - **基础配置**：应用名称"情侣课表"、AppID（点"重新获取"）、版本号、图标用 `icons/icon-512.png`
   - **启动界面**：可选关闭等待框 / 自定义启动图
   - **权限配置**：本应用不需要任何系统权限（不联网上传数据，只用本地存储）
   - **模块配置**：不需要额外模块
   - **代码视图**里可确认 `"plus": { "splashscreen": { "autoclose": true } }`
4. 菜单 **发行 → 原生App-云打包** → 选择 **Android(apk)** → 使用 DCloud 公共测试证书（或自有证书）→ 打包。
5. 生成的 APK 会自动做成 WebView 壳；`index.html` 里的 `fetch('manifest.json')` 在 App 内同样可用，PWA 与 App 互不影响。

> 也可以用 **uni-app（Vue）** 建项目，但需要把本单文件应用放进 `hybrid/html/` 用 `web-view` 承载，配置更麻烦；对纯前端单页应用，直接 **5+App** 最省事。
> 打包后如需"上课提醒""桌面小组件"，属于原生能力，需要额外插件（见下方第 8 条改进问题）。

## 五、使用说明

### 1. 导入课表
- **ICS 文件**：教务系统 → 课表 → 导出日历/ICS → 在 App 内"📥 导入 → 上传 .ics"→ 选择导入到"我方/情侣"→ 设置**学期第一周周一**（留空则自动取文件中最早一节课所在周的周一）→ 预览确认 → 追加/覆盖。
  支持 `SUMMARY`(课程名)、`LOCATION`(教室)、`DESCRIPTION`(教师)、`RRULE` 的 `COUNT/UNTIL`、`EXDATE` 停课。
- **粘贴文本**：支持两种常见格式，解析后可在预览里核对：
  ```
  高等数学A(1) 周一 第1-2节 1-16周 J06-101 张伟
  ```
  ```
  大学英语
  周二 第3-4节 {1-16周}
  J06A101
  李四
  ```
- **手动添加**：底部"➕ 添加"，或点击任意课程卡片 → 编辑。
- **周次写法**：`1-16`、`第1-16周`、`1-16周(单)`、`1-16周(双)`、`1,3,5,7`。

### 2. 情侣配对与同步（无后端，**异地也能用**）

> **异地恋正确姿势**：二维码要面对面扫，所以你们**用"复制文本发微信"这条路**。整条流程只需要 2 条微信消息，对方接受一次后，**以后每次打开都能看到你的课**，不用再导入。

**第一次（各做一次 + 互发一条微信）**
1. A 点"🔑 配对 → 生成配对密钥"，得到 `LOVE-XXXX-XXXX-XXXX`，微信发给 B；
2. B 点"配对 → 粘贴密钥 → 完成配对绑定"（这一步只做一次）；
3. A 点"🔄 同步 → **生成并复制同步包（直接发微信）**"，到微信里粘贴发送 —— 复制的内容自带使用说明，B 照着做就行；
4. B 点"🔄 同步"，把那条消息**整段粘进输入框**（前面带着昵称、换行、空格、表情都能自动识别），点【查看变更并接受】；
5. 反过来 B 发一次、A 接受一次 —— 现在两个人的手机里都能看到对方的课了。

**以后谁改了课表**：改的人点"生成并复制同步包"发过来，另一方粘贴接受即可。若清单里出现 **⚠️ 冲突**（同一门课两边都改过），逐条选【用 TA 的】/【保留我的】。

**其它可用的收发方式**（都走同一个加密包）
- 💾 **存成文件发送**：生成 `情侣课表同步包-日期.txt`，微信发文件；对方点"📂 从文件导入"
- 📷 **二维码**：只有见面时才有用（对方点"扫码导入"）
- 整段消息直接粘贴最省事，聊天软件加的换行/空格/零宽字符都会被自动清理

**冲突怎么处理（两边都改过同一门课）**
- 只有你改过、TA 没动 → 直接**保留你的**，不覆盖、不打扰；
- 只有 TA 改过 → 自动更新；
- 两边都改过 → 列为 **⚠️ 冲突**，每条都能选【用 TA 的】/【保留我的】（默认用 TA 的，也可一键全部选择）；
- 你本地新增的课不会被对方的同步顺手删掉。

**规则与安全**
- 同步包只包含**发送方自己那一套课表**；接受后只会合并进接收方的「情侣课表」，**绝不会覆盖接收方自己的课表**。
- 加密方式：`PBKDF2(SHA-256, 10万次) → AES-256-GCM`，口令就是配对密钥（双方一致）。密钥不同则解密直接失败。
- 课表数据先做 deflate 压缩再加密，实测 7 门课约 **730 字符**，一条微信轻松发完。
- 不做 WebSocket 实时推送，纯消息/扫码/文件，因此**没有后端、没有账号、没有服务器日志**。
- 接受后数据就存在本机 `localStorage`，**刷新、关掉、下次打开都还在**（除非手动清除浏览器数据）；拒绝同步 = 本地数据零改动。

### 3. 数据与备份
设置（⚙️）里可导出/导入 JSON 备份、载入示例数据、清空全部数据；也可修改总周数、开学日期、双方备注名。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 导入后周次不对 | 教务 ICS 里的日期决定了周次，需在导入时或设置里把**第一周周一**改成你们学校的实际开学日 |
| 单双周课程显示不对 | 手动编辑该课程，周次改成 `1-15单` / `2-16双` 这种写法 |
| Excel 导出没反应/变成 CSV | SheetJS CDN 被墙或离线，会自动降级导出 CSV（可用 Excel 直接打开） |
| 手机浏览器不提示"安装应用" | 必须 HTTPS + 已注册 Service Worker；iOS 请用 Safari 的"添加到主屏幕" |
| 换手机数据没了 | 数据只在本机，用"设置 → 导出备份 JSON"迁移，或用同步包让对象把课表发给你 |
| 加密同步包打不开 | 双方配对密钥必须完全一致（大小写、连字符都会被忽略，但字母数字必须相同） |
| 扫码没有反应 / 点扫码提示不支持 | 摄像头扫码依赖浏览器的 `BarcodeDetector`：**安卓 Chrome、微信内置浏览器、安卓 App（HBuilder 打包的 WebView）可用**；iPhone Safari 与部分桌面浏览器不支持 → 点【生成并复制同步包】把整段内容发微信，对方粘一下即可（异地本来就该用这个方式） |
| 二维码扫不出来 | 把 TA 手机亮度调高、放大二维码、距离 15~25cm；异地场景请直接用复制文本或发文件 |
| 页面打开是白的 / 很慢 | 已把 CDN 改成 `defer` 非阻塞并加了多源兜底（jsdelivr → unpkg → 百度静态库）；即使三个源全部不可用，课表、导入、同步、二维码仍可正常使用，只有 Excel 导出会降级成 CSV |
| 换浏览器后看不到原来的课 | `localStorage` 按浏览器隔离：用微信打开过、又用 Chrome 打开，是两份数据。**固定用一个浏览器**并把页面"添加到主屏幕"最稳 |

## 七、开发者自检

```bash
node _selftest/run.mjs        # 63 项逻辑单测（周次、ICS、文本解析、合并与冲突、QR 结构）
node _selftest/qr-crosscheck.mjs <qrcode模块路径>   # 二维码与参考实现逐位对拍（另需 jsqr 回读）
node _selftest/cdp-shot.mjs <url> <out.png> 390 1300 "loadDemo();render();" 800
```

`cdp-shot.mjs` 会用 Chrome DevTools Protocol 以真机尺寸渲染页面、执行任意 JS 并收集控制台错误，方便回归验证。
